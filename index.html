Ownership safeguards

  • Only the primary Owner can appoint or remove Admins and staff.
  • Staff are separate from Admins and cannot access Owner Controls.
  • Ownership transfer is not available in this panel.
  • Every role and staff access change is recorded in the Owner audit log.
  • All privileged database actions re-check the signed-in Owner identity.

Backup & recovery

Database backups and point-in-time recovery are managed in your Supabase project settings. This panel does not claim a backup exists or trigger a restore. Before a schema migration or major data change, verify your project's backup/PITR availability in Supabase Dashboard and test recovery using a separate project.

Open Supabase database settings

Data safety

  • No bulk deletion or destructive cleanup is exposed here.
  • Private message bodies are excluded from this report and CSV export.
  • Integrity checks are diagnostic counts, not automatic repairs.
  • Use Supabase's backup and restore tools for recovery; never treat a CSV inventory as a database backup.
